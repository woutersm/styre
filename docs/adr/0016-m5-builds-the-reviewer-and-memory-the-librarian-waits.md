# M5 builds the reviewer and memory; the librarian waits

v2's plan put three roles in M5: the reviewer, the curator and the librarian. M5 builds the
first two. The librarian was to cut the builder's orientation with a context pack per phase.
The planner's Where lists already did most of that: before the planner (2026-09) a phase made
39 to 79 tool calls before its first edit; in M3 it made 4 to 16, in M4 10 to 27. The reviewer
has evidence behind it: director reviews of the last four finished designs found 1 to 3 real
bugs each.

## Considered options

- All three roles, as planned: the librarian's gain over Where lists is unmeasured.
- The reviewer only: memory has no failure on record either, but it is the one channel
  that outlives a phase, and the curator is a single local completion.

## Consequences

The librarian comes back if orientation before the first edit grows again, for example
past 30 tool calls on planned designs.
